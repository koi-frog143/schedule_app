# schedule_app

My personal schedule app - an aesthetic Flutter timetable and class schedule application with customizable multi-alarm and push notification reminders, gallery image avatars, and Android home screen widget support.

## Features

- **Aesthetic Timetable & Daily Schedule**: Clean Folderly/retro inspired daily schedule cards.
- **Customizable Multi-Reminders**: Choose multiple intervals (5m, 10m, 15m, 30m, 1h) with individual toggles for audible alarms vs. silent push notifications.
- **Gallery Subject Avatars**: Choose custom subject pictures from your device gallery.
- **Android Home Screen Widget**: Quick glance at the upcoming or active class on your home screen.

## Getting Started

To run this application locally:

```bash
flutter pub get
flutter run
```
